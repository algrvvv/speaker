# Speaker

Нативный переводчик для строки меню macOS 15 и новее. Speaker переводит текст на устройстве через Apple Translation. При первом переводе macOS может предложить скачать языковые модели.

## Запуск

Собрать приложение из этого каталога и запустить его можно командой `make run`. Для сборки нужны Xcode или Command Line Tools с SDK macOS 26.4 или новее. Готовое приложение находится в `build/Speaker.app`.

## Как пользоваться

- Нажмите значок перевода в строке меню. Введите или вставьте текст, выберите языки и нажмите **Перевести**. Кнопка **Копировать** помещает результат в буфер обмена.
- Чтобы переместить окно, потяните за верхнюю часть рядом с надписью **Speaker**. Приложение запомнит позицию.
- **⌥⇧⌘T** открывает то же окно. Если активное приложение передаёт выделенный текст через API универсального доступа, Speaker вставит его и сразу начнёт перевод.
- Чтобы переназначить сочетание, откройте **⋯ → Настройки… → Изменить…** и нажмите нужные клавиши. Новое сочетание сразу применяется и сохраняется. Кнопка **По умолчанию** возвращает **⌥⇧⌘T**.
- В **⋯ → Настройки…** можно выбрать два основных языка. По умолчанию это английский и русский. В режиме **Автоопределение** Speaker берёт первый как резервный, если не удалось определить язык текста. Если перевод выполняется на первый язык, резервным становится второй.
- Кнопка **Поменять языки** между полями меняет направление перевода. Если результат уже есть, он становится исходным текстом для обратного перевода.
- Чтобы включить чтение выделения, откройте **⋯ → Разрешить чтение выделения…** и включите Speaker в **Системных настройках → Конфиденциальность и безопасность → Универсальный доступ**. После этого снова выделите текст и нажмите **⌥⇧⌘T**.
- Speaker запоминает выбранные языки. **⌘↩** запускает перевод, когда окно открыто.

Если после пересборки переключатель **Speaker** включён, а в меню приложения по-прежнему есть пункт **Разрешить чтение выделения…**, завершите старый процесс Speaker. Откройте новую сборку, удалите прежнюю запись из списка универсального доступа и добавьте готовый `build/Speaker.app` заново. macOS может сохранять старую запись разрешения, когда меняется локальная подпись приложения.

`make check` проверяет сборку, `Info.plist` и подпись приложения.
